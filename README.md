# 🎲 Dice Game

Developed as part of my web development practice.

A simple, interactive web application built to demonstrate fundamental front-end web development concepts. Two dice are rolled randomly, and the player with the higher score wins. If the scores are identical, the game declares a draw. 

This project is a perfect hands-on example of DOM manipulation, random number generation, and event handling in JavaScript.

---

## 🚀 Features

* **Randomized Gameplay:** Uses JavaScript's math functions to simulate authentic dice rolls.
* **Instant Win/Loss Logic:** Automatically calculates the scores and updates the UI in real-time.
* **Responsive Design:** Clean, minimalist UI built with CSS that looks great on both desktop and mobile screens.

---

## 🛠️ Tech Stack

* **HTML5:** Structures the game board and player elements.
* **CSS3:** Handles styling, layout, and visual presentation.
* **JavaScript (ES6):** Powers the core game logic, random number generation, and DOM updates.

---

## 📊 Core Concepts Covered

This beginner-friendly project serves as an excellent reference for:

* **DOM Manipulation:** Dynamically changing HTML text and image sources (`src` attributes) based on game outcomes.
* **Random Number Generation:** Utilizing `Math.random()` and `Math.floor()` to generate numbers between 1 and 6.
* **Control Flow:** Implementing `if/else` conditional statements to determine the winner.
